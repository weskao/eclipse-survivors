# Original boss attack sound candidates

Four original pre-rendered mono PCM WAV banks (32 kHz / 16 bit), 25 distinct attacks. Each attack owns a 3.25 s slot: actual windup from offset, silence to +2 s, then a 1.25 s release/tail. Filtered noise, resonant partials, swept pitch, transient trains, sub impact and decaying reflections; no external recordings. Reproduce using `node scripts/render-boss-attack-sfx.mjs`. Peak capped below 0.80 full scale. QA_PENDING: real-game audition, mastering and mobile speakers/headphones.
