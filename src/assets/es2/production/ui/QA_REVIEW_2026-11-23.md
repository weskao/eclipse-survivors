## 處理決策與缺口

1. **保留已入庫來源，不批次重繪。** 目前抽查無須另造同名資產；缺失是原生三倍來源不足、疑似斷片、部分重複動作、真正遊戲實測／人工簽核不完整。
2. 若要排除這些 blocker：先確認原始母圖是否保有真實細節，再對不合格格畫或整張幀做**真正重製**。不能單純放大 現有 WebP；必須先提交真實文件／素材，再由整合者同步 Canvas source rect 與 manifest / tests。
3. 任何 image update 須先新增 RED 回歸測試、驗證失敗，然後最小修正成 GREEN；核對 hash、Alpha、是否借用隔壁格、正確展示與 CI。
4. 外部英雄作業獨立；本分工不能修改 `src/assets/es2/production/heroes/**`。
5. 繼續保留 blocking QA gate，未獲授權人工確認不得把 `visual-review-required` 換成 approved。
6. 此文檔為 source-only 審查證據；**不可**誤寫成實際戰鬥 10 種敵人／4 魔王／全部場景或全部 UI 已通過瀏覽器驗收。
