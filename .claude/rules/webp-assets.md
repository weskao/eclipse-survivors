# Mandatory WebP image asset policy

- **WebP-first for all project raster art:** use local `.webp` for game/UI images, portraits, sprites, atlases, textures, backgrounds, decorations and screenshots. Convert required PNG-only display assets to WebP and update all imports, CSS/HTML, manifests, tests, scripts, cache/pack references and docs before removing their PNG copies. Do not keep redundant PNG exports of a WebP display asset.
- **Verify before deletion:** preserve dimensions, alpha, native 3× detail and color management; prefer lossless WebP with exact decoded RGBA verification for sprites, icons, UI and source conversions. Never replace a different existing WebP with a similar PNG. Check all tracked references (including dynamically resolved names), source provenance, animation, metadata, build and platform behavior. If a safe migration cannot be demonstrated, retain the PNG and document why. Never rename extensions without encoding, and never delete a sole source on filename similarity.
- **Compatibility/provenance exceptions:** keep platform-required or compatibility-sensitive PWA/iOS home-screen icons and social preview images in PNG when changing format is unsafe or unverified. Preserve original character masters, repair inputs, source hashes, QA/CI evidence and other irreplaceable source or metadata until a verified equivalent migration updates all consumers and provenance. Temporary PNGs from image/capture tools must not become committed display assets. No destructive blanket deletion.
- **Keep source-only evidence out of release bundles:** immutable provenance masters may stay in Git, but exclude their redundant display copies from `dist/` once every runtime consumer uses the verified WebP. Keep required platform icons and unrelated static assets intact. The release check must enforce this distinction.
- **After migration:** record converted/deleted paths, exceptions and exact byte/pixel validation; re-run relevant tests, `pnpm build` and `pnpm check-release`. Keep quality and visual QA gates intact.
